Files and their contents

Each run writes the same set of files to its output folder . The graph files hold one row per edge; map.json holds the full spline model.

map_digraph.html

Interactive viewer: hover an edge or node for its attributes, colour edges by diameter, blur, contrast or tier.

Open the interactive graph

map.graphml · map_edges.csv

The directed graph: nodes carry x, y and kind (bifurcation, endpoint, border, joint, junction). Edges carry the attributes in the table below.

map.json

The full model: nodes, per-edge spline control points and width / blur / contrast profiles, the background grid, and the fitting metadata. VesselNetwork.load() reads it back; fit-frames starts from it.

__EDGEJSON__

map_search_mask.png

uint8 labels, 1920 × 1200: 0 = background, 1 = mapped vessel tube (radius r + 3 px), 2 = faint-tier tube (radius 5 px). The viewer above shows it coloured.

map_summary.json

Counts, node kinds, total length, and every setting used for the map and the faint tier.

frames/frame_*.json · frames.csv

One fitted map per frame (same ids as the reference) and a row per frame: alignment, how far nodes moved, fit quality, and which edges are visible in that frame.
